# 你好，我是 accivlater 👋

独立开发者，做 **轻小说文库（Wenku8）的 iOS / iPadOS 客户端**。

## 当前项目

### 📱 [wenku8-ios](https://github.com/accivlater/wenku8-ios)

非官方轻小说文库阅读器，基于 [mikufoxxx/Wenku8_Flutter](https://github.com/mikufoxxx/Wenku8_Flutter) v0.4.8 修改，Flutter + Swift，GPL-3.0 开源。

- 支持 TXT / EPUB / MOBI / AZW3 等 13 种本地格式
- 原生 iPad 布局、系统朗读、Spotlight、快捷指令、局域网续读
- 源码开放，不提供 App Store / 预编译包
